# quickstart

supabase logging in (note this uses our project ID):

```
npx supabase login

npx supabase link \
  --project-ref uivgsszcikqrsrjopsdn

export SUPABASE_DB_PASSWORD='your-actual-database-password'
```

Pull the database

```
npx supabase db pull
```
